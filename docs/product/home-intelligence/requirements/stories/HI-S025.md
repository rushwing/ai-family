# HI-S025 — Define provider interface and mock provider

## Context

This R1 backend slice contributes to [HI-F009](../features/HI-F009.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define provider interface and mock provider. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A typed provider interface covers discovery, normalized state/event input and action execution results.
- The mock implements that interface without HA credentials, sockets or vendor dependencies.
- Deterministic time and injected failures allow reproducible timeout and retry tests.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
