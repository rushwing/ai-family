# HI-S021 — Execute HA capability actions asynchronously

## Context

This R1 backend slice contributes to [HI-F007](../features/HI-F007.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Execute HA capability actions asynchronously. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- An authorized confirmed switch/curtain action is submitted as a task through existing RabbitMQ task semantics.
- Retries preserve idempotency; uncertain physical outcomes are surfaced rather than blindly repeated.
- Configured completion policy determines terminal state; timeout and provider failure produce normalized results and audit evidence.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
