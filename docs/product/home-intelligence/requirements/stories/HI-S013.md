# HI-S013 — Discover HA registries and state

## Context

This R1 backend slice contributes to [HI-F005](../features/HI-F005.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Discover HA registries and state. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A fixture HA integration returns device, entity and area registries plus current state through its supported REST/WebSocket interfaces.
- Partial permission failure is explicit and does not appear as an empty successful inventory.
- Discovery output stays inside the integration boundary until mapping.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
