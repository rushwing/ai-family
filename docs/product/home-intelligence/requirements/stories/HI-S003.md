# HI-S003 — Define Home Assistant WebSocket lifecycle

## Context

This R1 backend slice contributes to [HI-F001](../features/HI-F001.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define Home Assistant WebSocket lifecycle. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A fake HA socket observes connect, authenticate and disconnect transitions.
- Transient disconnect schedules reconnect with configured bounded backoff; authentication rejection does not loop indefinitely.
- Shutdown cancels reconnect and closes the socket; health changes are observable.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.

## Acceptance Criteria

- [ ] A fake HA socket observes connect, authenticate and disconnect transitions.
- [ ] Transient disconnect schedules reconnect with configured bounded backoff; authentication rejection does not loop indefinitely.
