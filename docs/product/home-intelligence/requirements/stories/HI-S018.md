# HI-S018 — Expose scoped home-state query service

## Context

This R1 backend slice contributes to [HI-F006](../features/HI-F006.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Expose scoped home-state query service. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Authorized callers query home, areas, devices, states and capabilities through typed service methods.
- Unauthorized home/member access is denied before returning inventory.
- Missing and stale data have explicit results rather than a simulated healthy value.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
