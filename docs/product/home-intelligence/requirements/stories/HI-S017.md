# HI-S017 — Apply normalized events monotonically

## Context

This R1 backend slice contributes to [HI-F006](../features/HI-F006.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Apply normalized events monotonically. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A newer normalized event updates reported_state and observation metadata.
- Duplicate and older events do not regress state or create duplicate transitions.
- Offline and recovery events update availability while preserving last known reported state.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
