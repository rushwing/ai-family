# HI-S020 — Resolve actions into registered provider operations

## Context

This R1 backend slice contributes to [HI-F007](../features/HI-F007.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Resolve actions into registered provider operations. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A valid capability action resolves only through a registered binding and mapping.
- Unknown action, device, binding or invalid arguments returns a structured failure before provider dispatch.
- Provider operation identifiers do not become workflow or public API request fields.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
