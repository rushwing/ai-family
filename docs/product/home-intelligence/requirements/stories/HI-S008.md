# HI-S008 — Define canonical Home, Area and Device contracts

## Context

This R1 backend slice contributes to [HI-F003](../features/HI-F003.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define canonical Home, Area and Device contracts. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Home, Area and Device have validated stable IDs and explicit containment references.
- Given identical logical devices with different provider identities, the domain Device contract is unchanged.
- Public examples contain fictional inventory and no mandatory HA entity_id field.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.

## Acceptance Criteria

- [ ] Home, Area and Device have validated stable IDs and explicit containment references.
- [ ] Given identical logical devices with different provider identities, the domain Device contract is unchanged.
- [ ] Public examples contain fictional inventory and no mandatory HA entity_id field.
