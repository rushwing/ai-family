# HI-S011 — Define versioned Capability base contract

## Context

This R1 backend slice contributes to [HI-F004](../features/HI-F004.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define versioned Capability base contract. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A capability descriptor contains stable ID/version, properties/actions/events and input/output schemas.
- Action metadata states risk, timeout, idempotency and completion policy.
- The contract aligns with ADR-016 WoT interactions without requiring a full ontology runtime.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
