# HI-S024 — Reject unsupported and invalid actions

## Context

This R1 backend slice contributes to [HI-F008](../features/HI-F008.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Reject unsupported and invalid actions. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Unknown device/capability/action and invalid argument values are rejected with typed reasons.
- Read-only sensors cannot be used as write targets.
- Unsupported inputs never reach a provider; unsupported safety-sensitive operations are not guessed.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
