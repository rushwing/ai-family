# HI-S029 — Expose governed action-task API

## Context

This R1 backend slice contributes to [HI-F010](../features/HI-F010.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Expose governed action-task API. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Authenticated action submission uses the shared guard and returns a task reference with accepted semantics.
- Task lookup reports terminal outcome; idempotent retries do not issue another physical action.
- No route bypasses confirmation, audit, mapping or member policy; /api/tasks naming stays compatible with existing architecture drafts.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
