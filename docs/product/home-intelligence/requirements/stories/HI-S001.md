# HI-S001 — Define Home Assistant configuration

## Context

This R1 backend slice contributes to [HI-F001](../features/HI-F001.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define Home Assistant configuration. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Given no configured token, initialization fails with a redacted configuration error.
- Given private URL, token, timeout and reconnect settings, configuration validates them without embedding a secret in tracked files.
- Timeout and reconnect limits reject non-positive or unbounded values.
