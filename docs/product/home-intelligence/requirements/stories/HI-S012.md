# HI-S012 — Define six initial capability schemas

## Context

This R1 backend slice contributes to [HI-F004](../features/HI-F004.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define six initial capability schemas. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Switchable, Positionable, TemperatureSensor, HumiditySensor, PowerMeter and BatteryPowered schemas validate examples.
- Positionable rejects values outside its documented range; measurements declare units and availability.
- Sensor-only capabilities expose no write action, and unknown action names fail validation.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
