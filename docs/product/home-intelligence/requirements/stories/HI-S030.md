# HI-S030 — Verify canonical read and action smoke flows

## Context

This R1 backend slice contributes to [HI-F010](../features/HI-F010.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Verify canonical read and action smoke flows. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Mock read flow traverses provider, mapper, state store and API with canonical output.
- Mock action flow traverses API, guard, capability mapping and provider with task result and durable audit evidence.
- The suite covers failures and contains no required skipped checks; a separately recorded controlled HA/device demo proves the R1 physical-device exit criterion.
