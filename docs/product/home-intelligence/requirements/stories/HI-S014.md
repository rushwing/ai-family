# HI-S014 — Map registries into canonical home objects

## Context

This R1 backend slice contributes to [HI-F005](../features/HI-F005.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Map registries into canonical home objects. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Repeated discovery maps a fixture device to the same canonical ID and binding.
- Multiple entities on one device are represented without duplicate canonical devices.
- Unassigned areas and removed entities have documented mapping outcomes.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
