# HI-S028 — Expose canonical home-state query API

## Context

This R1 backend slice contributes to [HI-F010](../features/HI-F010.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Expose canonical home-state query API. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Authenticated routes expose canonical home/area/device/state queries with documented schemas.
- Queries filter resources using trusted identity and return explicit unauthorized/not-found/stale responses.
- The route contract reconciles the existing /api/twin/snapshot and /api/devices draft; raw HA schema is not the main public response.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
