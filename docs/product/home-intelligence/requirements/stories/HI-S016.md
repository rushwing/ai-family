# HI-S016 — Implement scoped current-state store

## Context

This R1 backend slice contributes to [HI-F006](../features/HI-F006.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Implement scoped current-state store. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- The in-memory store reads/writes canonical objects within an explicit authorized home/member scope.
- Unknown devices return a typed not-found result rather than creating state implicitly.
- The store exposes revision/freshness and documents provider snapshot reconstruction after restart.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
