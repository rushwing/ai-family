# HI-S007 — Reconcile current state after reconnect

## Context

This R1 backend slice contributes to [HI-F002](../features/HI-F002.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Reconcile current state after reconnect. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- After disconnect, a fresh snapshot plus buffered live events converges to the latest fixture state.
- An older snapshot or duplicate event cannot replace a newer reported state.
- Failed reconciliation marks state stale and retries within configured bounds.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
