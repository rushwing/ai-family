# HI-S006 — Normalize HA state change events

## Context

This R1 backend slice contributes to [HI-F002](../features/HI-F002.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Normalize HA state change events. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A bound fixture entity produces a canonical event containing canonical identity, reported state, observed_at and ordering metadata.
- Unknown or malformed entities produce a structured mapping error and no fabricated device state.
- Provider-specific payloads remain within the adapter/binding boundary.
