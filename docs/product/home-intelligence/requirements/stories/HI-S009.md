# HI-S009 — Define ProviderBinding contract

## Context

This R1 backend slice contributes to [HI-F003](../features/HI-F003.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define ProviderBinding contract. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- A binding records canonical device ID, provider identity and provider-owned mapping metadata.
- Replacing an HA binding with a mock binding preserves canonical identity.
- Invalid provider names or incomplete mappings are rejected.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
