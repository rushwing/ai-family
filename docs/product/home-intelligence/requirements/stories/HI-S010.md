# HI-S010 — Define canonical State contract

## Context

This R1 backend slice contributes to [HI-F003](../features/HI-F003.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Define canonical State contract. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- State separately represents desired_state, reported_state, availability, observed_at and monotonic ordering metadata.
- Unknown/offline state is distinguishable from a confirmed false or zero value.
- A provider ACK alone cannot be represented as confirmed physical convergence.
