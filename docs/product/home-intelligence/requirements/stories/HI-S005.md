# HI-S005 — Subscribe to HA state changes

## Context

This R1 backend slice contributes to [HI-F002](../features/HI-F002.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Subscribe to HA state changes. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- After authentication the client subscribes to state_changed and delivers fixture events to an adapter-owned callback.
- Reconnect restores one effective subscription; shutdown leaves none.
- Subscription rejection produces a health error rather than a silently empty event stream.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
