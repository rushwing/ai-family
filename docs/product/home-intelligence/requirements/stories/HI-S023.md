# HI-S023 — Persist append-only action audit evidence

## Context

This R1 backend slice contributes to [HI-F008](../features/HI-F008.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Persist append-only action audit evidence. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Allowed and denied attempts persist redacted requester/device/capability/action/task/trace, timestamp, outcome, duration and error records.
- App roles cannot update/delete audit rows and audit reads respect member scope and approved parent oversight.
- Audit persistence failure prevents unrecorded physical dispatch; retries correlate to the same task without losing attempt evidence.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
