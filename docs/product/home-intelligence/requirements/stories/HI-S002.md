# HI-S002 — Add authenticated Home Assistant REST client

## Context

This R1 backend slice contributes to [HI-F001](../features/HI-F001.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Add authenticated Home Assistant REST client. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Given a configured fake HA server, an authenticated runtime-info request returns a typed result.
- Given HTTP 401, timeout or unreachable server, callers receive distinct redacted errors.
- The token is absent from logs and public response payloads.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
