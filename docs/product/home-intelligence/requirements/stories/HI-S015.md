# HI-S015 — Infer supported capabilities deterministically

## Context

This R1 backend slice contributes to [HI-F005](../features/HI-F005.md). Existing legacy story references express related scope; they do not prove runtime delivery. See [CROSSWALK](../../CROSSWALK.md).

## Outcome

Infer supported capabilities deterministically. After merge this contract, service or verification increment is available independently; later callers may integrate it without enabling unfinished device writes.

## Scope

- Versioned mapping rules infer the six supported capability types from fixtures.
- Unsupported features remain unsupported rather than being guessed by an LLM.
- Each advertised action has a valid provider mapping and parameter schema.

## Non-goals

Other stories in the parent feature; R2 workflow behavior; new UI screens; arbitrary vendor actions; weakened authorization or confirmation.
