# HI-F108 — Cleaning Workflow

## Outcome

Cleaning and navigation workflows run through vendor-neutral capabilities without a purchased robot.

## User / System Value

Cleaning and navigation workflows run through vendor-neutral capabilities without a purchased robot. This capability is independently demonstrable through the scenario below.

## Scope

- R2 refinement defines typed Cleanable and Navigable contracts and MockVacuum.
- Definitions reference canonical areas/zones rather than vendor room IDs.
- Timeout, cancellation and partial failures have auditable outcomes.

## Non-goals

A required Roborock/Dreame purchase; vendor maps in core workflows.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] R2 refinement defines typed Cleanable and Navigable contracts and MockVacuum.
- [ ] Definitions reference canonical areas/zones rather than vendor room IDs.
- [ ] Timeout, cancellation and partial failures have auditable outcomes.
