# HI-F006 — Home State Store

## Outcome

Authorized consumers can query the latest known canonical household state.

## User / System Value

Authorized consumers can query the latest known canonical household state. This capability is independently demonstrable through the scenario below.

## Scope

- The initial current-state store supports home, area, device and capability queries with scoped access.
- Normalized events update state monotonically and distinguish offline from unknown.
- A restart rebuilds current state from a provider snapshot; durable action/audit state is not kept only in this cache.

## Non-goals

A complex history database; replacing durable task or audit storage.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] The initial current-state store supports home, area, device and capability queries with scoped access.
- [ ] Normalized events update state monotonically and distinguish offline from unknown.
- [ ] A restart rebuilds current state from a provider snapshot; durable action/audit state is not kept only in this cache.
