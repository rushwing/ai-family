# HI-F010 — Home API

## Outcome

Authorized clients can inspect home state and submit governed canonical action tasks.

## User / System Value

Authorized clients can inspect home state and submit governed canonical action tasks. This capability is independently demonstrable through the scenario below.

## Scope

- Queries expose canonical Home/Area/Device/State models and filter unauthorized resources.
- Action submission returns an asynchronous task reference and exposes terminal outcomes without claiming early physical success.
- Mock end-to-end tests cover read and write chains, authentication failures, invalid actions and audit correlation.

## Non-goals

New frontend UI; renaming deployed API routes without a compatibility decision.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] Queries expose canonical Home/Area/Device/State models and filter unauthorized resources.
- [ ] Action submission returns an asynchronous task reference and exposes terminal outcomes without claiming early physical success.
- [ ] Mock end-to-end tests cover read and write chains, authentication failures, invalid actions and audit correlation.
