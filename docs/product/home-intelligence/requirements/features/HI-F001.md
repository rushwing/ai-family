# HI-F001 — Home Assistant Connection

## Outcome

A configured HA integration authenticates, reports health and recovers from connection loss.

## User / System Value

A configured HA integration authenticates, reports health and recovers from connection loss. This capability is independently demonstrable through the scenario below.

## Scope

- HA URL and credentials come from documented private configuration.
- REST runtime metadata is returned after successful authentication; invalid credentials produce a redacted structured error.
- WebSocket authentication and bounded reconnect are observable through connected, disconnected, auth_failed and reconnecting health states.

## Non-goals

Vendor protocol reimplementation; workflow execution.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] HA URL and credentials come from documented private configuration.
- [ ] REST runtime metadata is returned after successful authentication; invalid credentials produce a redacted structured error.
- [ ] WebSocket authentication and bounded reconnect are observable through connected, disconnected, auth_failed and reconnecting health states.
