# HI-F105 — Sleep Workflow

## Outcome

A reviewed sleep scene coordinates supported devices and records the resulting home mode.

## User / System Value

A reviewed sleep scene coordinates supported devices and records the resulting home mode. This capability is independently demonstrable through the scenario below.

## Scope

- Only supported and authorized curtain/light/TV/HVAC actions appear in the reviewed definition.
- Unavailable optional devices have explicit skip/failure behavior.
- Home mode changes only according to the defined completion rule.

## Non-goals

Learning bedtime routines; inventing unsupported TV/HVAC capability schemas.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] Only supported and authorized curtain/light/TV/HVAC actions appear in the reviewed definition.
- [ ] Unavailable optional devices have explicit skip/failure behavior.
- [ ] Home mode changes only according to the defined completion rule.
