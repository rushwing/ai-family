# HI-F009 — Mock Home / Simulation

## Outcome

Domain and capability behavior can be developed and tested without HA or purchased hardware.

## User / System Value

Domain and capability behavior can be developed and tested without HA or purchased hardware. This capability is independently demonstrable through the scenario below.

## Scope

- A mock provider implements the same discovery/state/execution contracts as the HA adapter.
- MockSwitch, MockCurtain and MockTemperatureSensor produce deterministic state transitions and failure fixtures.
- Provider contract tests run without HA credentials or network access.

## Non-goals

MockVacuum or MockFeeder implementation in R1; a physics simulator.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] A mock provider implements the same discovery/state/execution contracts as the HA adapter.
- [ ] MockSwitch, MockCurtain and MockTemperatureSensor produce deterministic state transitions and failure fixtures.
- [ ] Provider contract tests run without HA credentials or network access.
