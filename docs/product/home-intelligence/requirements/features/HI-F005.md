# HI-F005 — Entity / Device Mapper

## Outcome

HA devices, entities and areas map deterministically to stable canonical objects.

## User / System Value

HA devices, entities and areas map deterministically to stable canonical objects. This capability is independently demonstrable through the scenario below.

## Scope

- Discovery reads HA registry and state inputs with structured errors for missing permissions.
- Repeated discovery preserves canonical identity and spatial assignment; bindings isolate provider identifiers.
- Capability inference uses versioned deterministic rules; unsupported entities are reported without granting invented actions.

## Non-goals

Mapping every HA integration; exposing raw registries as the public API.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] Discovery reads HA registry and state inputs with structured errors for missing permissions.
- [ ] Repeated discovery preserves canonical identity and spatial assignment; bindings isolate provider identifiers.
- [ ] Capability inference uses versioned deterministic rules; unsupported entities are reported without granting invented actions.
