# HI-F002 — Home Assistant Event Synchronization

## Outcome

Current household state converges after live changes and reconnects.

## User / System Value

Current household state converges after live changes and reconnects. This capability is independently demonstrable through the scenario below.

## Scope

- state_changed is the primary live update source; fixed-interval polling is not the primary synchronization mechanism.
- Provider events become canonical events with identity, observation time, freshness and correlation metadata.
- Reconnect reconciles a fresh snapshot; duplicate and older events cannot overwrite newer state.

## Non-goals

Historical event intelligence and cross-device correlation.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] state_changed is the primary live update source; fixed-interval polling is not the primary synchronization mechanism.
- [ ] Provider events become canonical events with identity, observation time, freshness and correlation metadata.
- [ ] Reconnect reconciles a fresh snapshot; duplicate and older events cannot overwrite newer state.
