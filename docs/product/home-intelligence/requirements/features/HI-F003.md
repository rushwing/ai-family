# HI-F003 — Canonical Home Domain Model

## Outcome

Home, Area, Device, Capability, State and ProviderBinding have stable vendor-neutral identities.

## User / System Value

Home, Area, Device, Capability, State and ProviderBinding have stable vendor-neutral identities. This capability is independently demonstrable through the scenario below.

## Scope

- Canonical Home, Area and Device contracts validate identities and references.
- Provider IDs remain inside explicit ProviderBinding records and adapter code.
- State distinguishes desired_state, reported_state, availability, observed_at and revision.

## Non-goals

Multi-floor spatial intelligence; one domain class per HA entity.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] Canonical Home, Area and Device contracts validate identities and references.
- [ ] Provider IDs remain inside explicit ProviderBinding records and adapter code.
- [ ] State distinguishes desired_state, reported_state, availability, observed_at and revision.

## Dependencies

None at feature level. Story dependencies govern independently mergeable increments.
