# HI-F103 — Trigger & Condition Engine

## Outcome

Explicit time/event triggers evaluate deterministic conditions against canonical state.

## User / System Value

Explicit time/event triggers evaluate deterministic conditions against canonical state. This capability is independently demonstrable through the scenario below.

## Scope

- Triggers and conditions use canonical events and state with typed operands.
- Duplicate trigger delivery does not create duplicate runs.
- Time zones, stale state and missing sensor values have explicit outcomes.

## Non-goals

R4 derived event intelligence; arbitrary code execution.

## Architecture Boundaries

Inherit [architecture alignment](../../ARCHITECTURE_ALIGNMENT.md), ADR-016 and ADR-010. Provider identifiers stay in adapters and ProviderBinding; device writes remain governed asynchronous tasks.

## Acceptance Criteria

- [ ] Triggers and conditions use canonical events and state with typed operands.
- [ ] Duplicate trigger delivery does not create duplicate runs.
- [ ] Time zones, stale state and missing sensor values have explicit outcomes.
