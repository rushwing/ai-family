## Preconditions

- Use isolated in-memory version-1 inventories and the public apartment fixture.
- Exercise the eventual public contracts in `libs/state-schema`; no HA credentials or services are required.

## Steps

1. Parse and serialize a complete inventory, then parse the serialized result and compare every canonical field and reference.
2. Parameterize all five residence types and every supported area type from REQ-013, including `other`.
3. Omit optional aliases and labels; repeat with explicit empty lists and populated values. Keep nullable containment fields explicit.
4. Validate canonical devices without entity IDs, provider IDs, capability or state payloads; simulate changing external provider metadata while reusing the same canonical device.
5. Add unsupported structural fields at the envelope and each object kind, including provider/capability fields on Device.

## Expected Results

- AC1: all supported values round-trip without losing IDs, names, labels, aliases, group membership or references; omitted optional lists default to `[]`.
- Canonical Device fields and IDs remain identical across external provider replacement; no provider dependency is required to construct or validate them.
- AC3: unknown structural fields fail at their field paths rather than being discarded; external provider metadata is not embedded in this inventory contract.
