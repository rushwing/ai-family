## Preconditions

creation rights. Tests create and remove only a randomly named test database;
apply migrations 0001–0006 twice. Runtime uses SET LOCAL ROLE aifam_app and

missing database a failure; unavailable/broken psycopg fails import.

## Steps and expected results

1. Issue a proof-bound token; consume it through another store and a separate
   Python process; token and proof replays fail across newly constructed stores.
2. Race 16 consumption attempts on independent connections: exactly one wins.
   Race 16 identical proof claims: exactly one token is issued.
3. Change member, session, tool or exact parameters: consume fails without
   consuming the valid original. Expired tokens and old/future proof timestamps
   fail using database time.
4. Inject an INSERT failure after nonce claim: neither token nor nonce commits;
   retry the same proof after removing the fault succeeds.
5. Query as another member: no token/nonce rows leak. Stored gateway tokens are
   SHA-256 digests, not raw bearer values. Existing check-in token/task records
   remain outside the gateway versioned protocol.
6. With the database unavailable, return a fixed redacted failure; no memory
   fallback or executor call occurs. Compose the real durable store with the
   HTTP boundary and verify proof replay and exact token binding across apps.
7. MCP CI supplies PG16, triggers on migration changes, saves JUnit and rejects
   missing, skipped, failed or errored prerequisite suites.
