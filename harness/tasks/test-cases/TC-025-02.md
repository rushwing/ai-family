## Preconditions

[REQ-025](../features/REQ-025.md) authorizes combined proposed tests and implementation for the post-merge findings. Generator-authored, pending external review; no independent acceptance is claimed.

## Steps and expected results

Verify exact official filename and SHA256 before any install. Hermetic fixtures cover success, altered bytes, missing/duplicate/sdist entries, invalid hash, mirror URL, unexpected files, empty wheelhouse and unavailable metadata. Build a fresh wheelhouse with explicit official index, disabled config/cache, redacted acquisition records and fail closed on verification errors.

## Implementation location

`toolsets/iot/home-device-fabric/tests/test_artifact_provenance.py and artifact_provenance.py`. Runtime tests use fictional credentials and fake/loopback peers; hermetic digest tests never access the index. Fresh builds separately access official package metadata.

## Local pre-review regression extension — 2026-10-16

redirected URL fails with dependency_metadata_redirect. Removing only that guard
must fail the real regression. Missing/duplicate/oversized wheel METADATA and

download; metadata fetching uses an explicitly empty ProxyHandler even under
hostile proxy environment. Removing either proxy exclusion must fail the fixture.
