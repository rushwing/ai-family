## Steps

1. Parameterize selectors with both area_ids and area_group_ids, neither form, empty lists, duplicate IDs and wrong scalar/list/item types.
2. Test unknown and wrong-kind area/group/label IDs, nonexistent Home IDs and a different Home ID; test repeated label IDs even when all are registered.
3. Run valid area/group/label selection and valid empty resolutions with the same spies installed.
4. Repeat failures and compare error locations; compare the input snapshots after every call.

## Expected Results

- AC5/AC6: each malformed or foreign selector is rejected explicitly with an actionable field path; no partial target list or whole-home fallback is returned.
- Valid empty selection results remain empty; they are distinguishable from invalid-selector errors.
- The resolver makes zero network/provider/dispatch/device-write calls on success, empty results and failure, and does not mutate the inventory or selector. Labels/groups confer no authorization.
