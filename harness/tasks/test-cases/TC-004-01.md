## Steps and expected results

1. Register read/write/high tools missing supported auth or a test reference:
   registration fails. High-risk tools missing two-phase confirmation fail.
2. Invoke the authenticated wrapper directly with missing/garbage/expired JWT,
   wrong issuer/audience, kid role, cross-member parameters or tampered signature:
   deny with zero handler calls. The wrapper reauthenticates instead of trusting
   the gateway's body or a caller-supplied claims dictionary.
3. Allow a fixture home grant: the handler's actual PostgreSQL connection uses
   aifam_app and app_current_member() from the verified JWT. A fresh transaction
   sets member scope on each call; another member cannot read the first's rows.
4. Deny or break the injected current-resource policy: zero handler calls.
   Caller parameter dictionaries and registered metadata are detached.
