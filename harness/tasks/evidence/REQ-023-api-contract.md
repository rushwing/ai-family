# REQ-023 proposed API and TC contract

Frozen by generator-001 before runtime implementation, under human combined-delivery authorization recorded in [REQ-023](../features/REQ-023.md). This is proposed test authorship, not independent acceptance.

Module: home_device_fabric.ha_rest. __all__ exactly HARestClient, HARuntimeInfo, HARestError. Client takes only HAConfiguration; async runtime_info(*, correlation_id: str), aclose and context-manager methods. Missing ID is signature TypeError; exact-string ASCII 1–64 [A-Za-z0-9][A-Za-z0-9._-]* IDs reject complete token/endpoint substrings, invalid IDs yield invalid_correlation_id with None. Client/result repr is constant; immutable version-only result exports a fresh {version: string}. Errors expose code/correlation_id/http_status only; args/str code only; cause/context None. Status is 401 for auth_failed, actual non-200 for http_error, otherwise None. Client raw serialization/copy is refused.

Accepted versions are exact str, length 1–128, every codepoint 33–126, with complete token/endpoint echoes rejected. Examples: 2025.1.0, 2024.11.0.dev20241014, 2023.9.0b0. Non-object/missing version/invalid type/duplicates/non-finite JSON/invalid UTF-8/media/charset/compression/oversize reject as invalid_response. Body cap is literal 262144 bytes, enforced during raw streaming. Status classification precedes body reading.

An admitted call sends exactly one GET to base_url + /api/config, Bearer credential and JSON Accept/identity encoding. HTTPX range >=0.28.1,<0.29, trust_env false, redirects false, TLS verification true, retries zero; operation owns fresh transport/client/response and closes them. No cookies survive an operation. All non-200 except 401 map http_error; no redirect follow-up. Connection/DNS/TLS maps transport_failed. Deadline and cleanup-guard expiry map timeout. Explicit cancellation propagates.

One active request; ID check precedes closed then busy check; rejections dispatch zero. aclose marks closed before waiting, drains admitted request without replacing its outcome/extending deadline, does not wait on the caller's whole task, and uses a completion event. Repeated/cancelled close waiters never cancel the active request or reopen client. Overall monotonic request deadline includes setup/header/body work and is rechecked before publishing; >= deadline wins over ordinary result/error. One total 1000 ms cancellation-safe cleanup guard is separate from successful network budget; it is not restarted across resources/waiters. Synchronous work and resolver workers are not forcibly preempted.

TC-023-01–06 own literal positive/negative/race/wire expectations as declared in their Markdown. Required mode must reject runtime/dependency absence and mandatory skips in hermetic stub layouts. Source matrix and direct/sdist-compatible installed pairs must actually use HTTPX for success/timeout/TLS-failure/close, under -I and -O; dependency versions/hashes and tested source are recorded separately from independent acceptance.
