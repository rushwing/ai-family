Module home_device_fabric.ha_configuration exports HAConfiguration and HAConfigurationError. Existing top-level exports are unchanged. HAConfiguration(settings: object, *, access_token: object = missing) validates a plain dict (exact type, string keys of exact str type; subclasses reject) and separate plain str token. Missing token has missing_token; supplied None/invalid has invalid_token. Read-only properties: schema_version, base_url, request_timeout_ms, reconnect_initial_delay_ms, reconnect_max_delay_ms, reconnect_max_attempts. Deliberate access_token_for_transport() -> str; reconnect_delays_ms() -> tuple[int, ...]; to_redacted_dict() -> dict[str, int | str]; to_redacted_json() -> str (sorted compact JSON).

Exact snapshot fields/defaults: {"schema_version":1,"base_url":"<redacted-endpoint>","access_token":"<redacted>","request_timeout_ms":10000,"reconnect_initial_delay_ms":1000,"reconnect_max_delay_ms":30000,"reconnect_max_attempts":8}. No raw endpoint, scheme, token metadata or token-derived value. repr/str uses that snapshot inside HAConfiguration(...). Containers inherit safe repr. vars/asdict/default JSON reject; pickle/copy refuse configuration and credential wrapper. Private slot traversal/debugger/memory is excluded; deliberate endpoint property and token accessor return connection inputs. No raw to_dict, dataclass or dict state export.

HAConfigurationError is ValueError with code: str and path: tuple[str, ...], args/message equal code + ': ' + '.'.join(path). Paths contain only settings, <unknown>, access_token or declared field names. Code vocabulary: invalid_settings (non-plain dict or non-string key, path settings); unknown_field (path settings.<unknown>); missing_field (settings.schema_version/base_url); invalid_setting (wrong integer type or unsupported base_url string type, respective declared field); unsupported_version (strict integer !=1); out_of_bounds (strict integer outside inclusive bounds); invalid_endpoint (base_url grammar/length); missing_token; invalid_token (access_token); invalid_reconnect_order (settings.reconnect_max_delay_ms). Error precedence: settings shape/keys/unknown/required, version, endpoint, numeric limits/order, token. All diagnostics are value-free; parser exceptions are caught and the fixed error is raised outside handlers, leaving no library parser cause/context. Subclasses of primitive inputs reject before invoking their overridden behavior.

Endpoint grammar and limits are fixed in REQ Q1–Q6: ASCII root HTTP(S), strict DNS/IPv4/bracketed IPv6, no trailing DNS dot/IPv6 zones/legacy hexadecimal numeric IP forms, explicit ports retain spelling including defaults, single slash stripped; no permissive URL parser fallback. No runtime I/O, network, clock, randomness, environment or credential source.

Diagnostics use to_redacted_dict()/to_redacted_json(); trusted transport composition uses base_url plus access_token_for_transport(). The latter return the normalized endpoint and original credential and must not be logged. Explicit port spelling preservation means equivalent endpoints can have distinct stored strings (:443 versus :00443); endpoint-equivalence comparison/deduplication is not supplied by this API.

Settings key scans follow dict insertion order, but every unknown key maps to the identical unknown_field/settings.<unknown> diagnostic. Insertion order therefore does not change the visible unknown-key error. All non-string keys are rejected before the unknown-key scan. Required fields are checked schema_version then base_url; numeric settings are checked request_timeout_ms, reconnect_initial_delay_ms, reconnect_max_delay_ms, reconnect_max_attempts, independently of input insertion order.

The endpoint printable-ASCII scan and authority ?/# exclusions deliberately overlap later host/port/root checks. The supplied pre-review reports equivalent mutations at these layers; that observation does not establish a missing behavioral expectation or justify removing explicit grammar guards. Raw serialization refusals also overlap (__getstate__/__reduce__/__reduce_ex__); retain all documented refusals.
